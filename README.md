# Xelvur Bot Website

Адаптивный веб-сайт для Telegram бота Xelvur - защита от спама и нелегала.

## 🎯 Особенности

- **Адаптивный дизайн** - работает на PC, планшетах и мобильных устройствах
- **Минималистичный стиль** - чистый, современный интерфейс
- **Быстрая загрузка** - оптимизирован для скорости
- **SEO-готов** - хорошая индексация в поисковиках

## 📁 Структура проекта

```
xelvur-bot-website/
├── index.html       # Основная страница
├── styles.css       # Стили и адаптивность
├── script.js        # JavaScript функциональность
└── README.md        # Документация
```

## 🚀 Установка

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Или разверните на любом хостинге (GitHub Pages, Vercel, Netlify и т.д.)

## ✨ Функциональность

- Адаптивная навигация с мобильным меню
- Героический раздел с красивой анимацией
- Секция особенностей с карточками
- Раздел преимуществ
- Информация о боте
- CTA секция для добавления в Telegram
- Адаптивный подвал

## 🎨 Цветовая схема

- Основной: `#6366f1` (Indigo)
- Вторичный: `#4f46e5` (Dark Indigo)
- Акцент: `#ec4899` (Pink)

## 📱 Адаптивность

Сайт полностью адаптирован под:
- Десктопы (1200px+)
- Планшеты (768px - 1200px)
- Мобильные устройства (480px - 768px)
- Маленькие мобильные (< 480px)

## 🔧 Кастомизация

Измените следующие значения в коде:
1. Ссылку на Telegram бота в `script.js`
2. Текст и описание в `index.html`
3. Цвета в CSS переменных в `styles.css`
